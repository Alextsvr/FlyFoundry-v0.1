# Real-world evidence fitness (not implemented in v0.1)

Planned design: a registry of public, legitimately accessible datasets (URL, licence, access date, SHA-256 of the fetched snapshot) under `data/evidence/`;
a hypothesis may only cite registry entries; unsupported assertions are penalised. Tiers: synthetic benchmark score → evidence-supported hypothesis →
validated customer demand → actual paying customer → real collected revenue. v0.1 contains no evidence dataset, so every hypothesis is tier 1 and revenue is
EUR 0 / unknown. No URLs, sources, competitors or customers are invented anywhere in the code or reports. No scraping, outreach, accounts or payments are performed.
